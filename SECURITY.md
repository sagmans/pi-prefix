# Security Policy

## Supported versions

Only the latest released line of `@sagmans/pi-prefix` is supported with
security fixes.

## Pi packages run with your privileges

A Pi package is code that runs on your machine with your user privileges when
Pi loads it. Review any package before installing it, including this one.

## Reporting a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting
(GitHub Security Advisories) for `sagmans/pi-prefix`. Do not open public
issues for unpatched vulnerabilities; public reports about an unpatched flaw
put every user at risk.

Include the package version, the config layers involved, and reproduction
steps where possible.
